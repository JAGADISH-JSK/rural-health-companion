[1:00 — ARCHITECTURE]
(show assets/architecture_diagram.png)
Let's take a look at the system architecture. (pause)
When a user submits a query, it starts at the START node and immediately enters the Security Checkpoint. This node checks for prompt injections, redacts PII like phone and Aadhaar numbers, and blocks dangerous substance or prescription queries.
If the check passes, the Orchestrator routes the request to either the Health Companion agent or the Agriculture Advisor agent.
These specialist agents make call requests to our local MCP Server, fetching nearby clinics, crop diseases, or agricultural parameters.
Before the final advice is rendered, it must pass through the Disclaimer Gate, which acts as a Human-in-the-Loop constraint. The user must type "agree" to proceed.
Once accepted, the final output is shown via the Final Output node.

[3:00 — SECURITY & MCP]
This strict Security Checkpoint ensures that no dangerous queries or personal credentials leak. Simultaneously, our Model Context Protocol server connects the agents to local databases dynamically, bringing immediate, offline-capable database access directly to the model's reasoning loop.
